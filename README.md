# 喵喵预设整理 · Meow Preset Tools

在 SillyTavern 原生聊天补全预设列表上，增加分组、搜索、便捷移动、复制和撤销。条目仍使用原生编辑框。

本项目从 Meow-Preset-Workbench 0.3.1 的分组与基础模块拆出，独立安装、独立维护。工作台项目暂停改动，跨预设整理与注入地图继续由工作台项目负责。

0.1.2 在视觉、交互和性能优化基础上补充 TT 2.4.0 适配：同步 CodeMirror 正文、处理安卓返回关闭弹窗、复用宿主文件导出，并识别 Agent 生成状态。列表减少框线、沿用酒馆主题色；多选可直接带入分组，手机选中后直接显示分组操作。搜索、折叠、勾选与落点调整复用当前快照和控件，不再每 400ms 克隆整份预设。

## 安装

在 SillyTavern / TT 酒馆的扩展安装页面粘贴仓库地址：

```text
https://github.com/demilich1117/Meow-Preset-Tools
```

也可从 [Releases](https://github.com/demilich1117/Meow-Preset-Tools/releases) 下载 ZIP。SillyTavern 手动安装时，把安装包中的 `Meow-Preset-Tools` 文件夹放进 `data/<用户>/extensions/`，确认文件夹下直接包含 `manifest.json`，然后刷新酒馆。TT 使用其扩展安装入口，不需要修改酒馆核心文件。

使用本扩展前，停用 `Meow-Preset-Workbench`、旧独立分组扩展或内置分组的喵喵脚本库，避免同时管理原生列表。本扩展发现工作台或旧脚本库时会暂停列表和编辑增强，扩展设置中显示原因。

现有 `extensions.miao_prompt_groups` 分组直接沿用。也只读显示 `fruitHeartSections` v1 和有效的 `entryGrouping` inclusive 分组范围；不把装饰性分隔标题自动转换为分组。

## 整理原生列表

- **在列表中选落点**：点条目左侧拖柄，原列表进入点选模式。点目标条目、选之前／之后，列表显示插入线；点「放在这里」完成。可边滚动边挑位置，也可搜索或直接选开头／末尾，取消不改顺序。
- **搜索移动**：右侧「••• → 搜索移动到…」打开可搜索的目标列表，适合通过名字快速找落点。
- **短距离移动**：按住拖柄拖动，有插入占位和边缘滚动；聚焦拖柄后按 Alt + ↑ / ↓ 可上下移位。搜索过滤期间使用「移动到…」，清空搜索后恢复拖拽。
- **跟随滚动的操作栏**：桌面和手机都在列表滚动时保留顶部工具，无需反复上滑。小屏上工具栏高度受限，保留列表阅读空间。
- **一步新增**：点工具栏「新增」，填写原生编辑框后点保存，直接选择插入位置，再点「创建并插入」。可选择加入后启用；取消选位置会保留原编辑内容，不创建孤立条目。整个新增操作可以一次撤销。原生自带的新增按钮也使用相同流程。
- **批量整理**：点「多选」勾选条目，可点选落点、搜索移动、复制或移出列表。Shift 点击支持连续选择，折叠组可以整组选择；筛选外仍选中的数量会显示出来。
- **直接分组**：多选后的「分组…」或顶部「分组」会带入当前选择，不必重新勾选；单个条目的「••• → 分组…」也可直接整理。在手机上选择条目后自动显示新建／移入分组操作，可收起后继续选条目。
- **连续操作**：移动面板切换前后位置不会重建控件；按 Esc 仅取消当前移动，焦点回到搜索。Alt + ↑ / ↓ 移动后保留拖柄焦点，可连续调整；搜索无结果时有明确提示与清除入口。
- **复制**：创建独立 ID 的副本，放在最后一个选中条目之后，保留正文、角色、深度、条件和分组。副本默认停用，名称附加「（副本）」。
- **移出列表**：只移出当前顺序，正文和其他角色顺序保留，可从酒馆原生条目库重新添加。内置条目受到保护。
- **撤销**：可撤销本次会话最近 20 次整理操作，包括分组与原生拖拽。其他编辑、切换预设或保存后，不会使用旧撤销记录覆盖新内容。

分组按原顺序显示；非连续成员显示「续」段，不擅自搬动条目。搜索匹配名称、正文和组名，临时展开匹配条目，清空搜索恢复折叠。分组管理器中点「应用分组到草稿」后回到原生列表。

整理操作沿用酒馆原生草稿，并保存到当前设置。点「保存到预设」才更新预设文件，同时保存该预设的其他当前草稿。原生编辑框尚未关闭、生成中、预设已切换或保存过程中内容变化时，会阻止过期写入。保存前保留最近三份原预设备份，可在扩展设置中下载。

## 原生条目编辑

宏自动弹出默认关闭，可通过编辑框上的按钮开启。只影响原生预设正文获得焦点时的宏建议，不修改全局宏设置。

- 「展开正文」提供大面积编辑，应用后回到原生编辑框，再用原生保存按钮保存条目。
- 「查找与变量工具」默认折叠，支持正文查找、定位当前 set/get、插入已有固定变量的 get，以及缺失、停用、后置和覆盖检查。
- 正常空值初始化链显示为说明；变量检查不执行宏，不补写任意变量值。脚本、世界书、动态变量名和模型的实际输出不属于静态验证范围。

TT 启用代码编辑器时，分析与展开会先获取尚未保存的最新正文。扩展的变量插入／定位使用展开窗口预览，点「应用回编辑框」同步回 TT，再按原生保存按钮保存条目；也可直接用 TT 自带的查找替换。展开应用整段修改会重置 TT 代码编辑器内部撤销记录，未修改正文时不重置。

## 宿主与验证范围

- SillyTavern 1.19.0（`06bde939f`）：真实加载器和预设管理器的桌面、390px 触控及 320px 窄屏回归；见 [视觉与性能记录](validation-2026-11-14.md)。
- TT 2.4.0（`85dc99089e3fcc9d3a0aafc085564bd642895261`，兼容 ST 1.19.0）：核对官方源码并使用实际 TT 预设管理器、CodeMirror 和返回桥模块做隔离浏览器验证；范围与限制见 [TT 适配记录](validation-tt-2026-11-14.md)。未实测 TT 原生 WebView、实体手机、系统软键盘或原生文件分享。
- TT 2.4 的窗口已经扣除系统栏与停靠键盘，扩展使用宿主给出的可用视口，不再叠加键盘偏移。缺少 Web Locks 的 WebView 仍可整理草稿，但显式保存会报错，避免绕过跨窗口写入保护。
- TT Agent 状态接口不可用时暂停整理写入；旧 TT 版本未认证。此扩展仅处理聊天补全预设。

## 开发

纯前端 ES 模块，无构建步骤。运行 `npm test` 检查顺序操作、撤销隔离、快照复用、显式保存和备份失败保护。

```sh
node tools/host-check.mjs <Playwright模块路径> <运行中的酒馆URL>
node tools/host-check.mjs <Playwright模块路径> <运行中的酒馆URL> --performance
node tools/prepare-tt-check.mjs
node tools/host-check.mjs <Playwright模块路径> <运行中的ST酒馆URL> --tt
node tools/host-check.mjs <Playwright模块路径> <运行中的ST酒馆URL> --tt --performance
```

浏览器脚本通过真实酒馆加载器和 PromptManager 运行，但拦截预设、设置保存，所有验收数据只存在于临时浏览器。它暂时恢复原生抽屉布局，保留主题颜色，避免已安装 UI Dock 的配套布局在隔离后造成干扰。

TT 检查准备脚本会下载固定提交的少量宿主源码和 CodeMirror 验证依赖到被 Git 忽略的 `output/`。`--tt` 在 ST 测试壳中替换实际 TT 前端模块，其余 context、表单、持久化传输仍来自 ST；它不替代原生 TT 设备验证。扩展本身无第三方构建依赖，安装包不包含宿主源码或这些测试依赖。

性能检查使用 304 条目、约 54 万正文字符，统计预设快照读取、扩展界面更新和原生列表渲染次数；计数仅注入测试副本，不包含在扩展运行代码中。操作前仍重新校验真实草稿，缓存仅用于显示，不用于绕过切换预设或外部编辑保护。
